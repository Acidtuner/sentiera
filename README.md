# Sentiera — Frontier AI Venture Studio & Digital Agency

Official repository for **Sentiera Technologies LLC**, an AI venture studio and digital agency operating from Masdar City, Abu Dhabi, UAE.

---

## Technical Stack

- **Framework**: [Next.js](https://nextjs.org/) 14 (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Typography**: Geist Sans & Geist Mono
- **Icons**: Lucide Icons & Custom Industrial SVGs
- **Language**: TypeScript

---

## Architectural Philosophy & Design Tokens

- **Vibe**: High-end boutique engineering firm. Minimalist, clinical, and authoritative.
- **Palette**: Stark white background (`#FFFFFF`), deep slate text (`#08090A`), and Tech Blue (`#0066FF`) accents.
- **Typography**: 
  - **Geist Sans**: Tight tracking for bold, authoritative headlines.
  - **Geist Mono**: Wide tracking in uppercase for metadata, coordinates, and technical UI.

## Getting Started

### Prerequisites

- Node.js 18+ (tested with Node 20 / 24)
- npm or pnpm

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Production Build

```bash
npm run build
npm run start
```
